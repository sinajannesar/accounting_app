# نرم‌افزار حسابداری آفلاین

یک برنامه حسابداری ساده، آفلاین و فارسی برای ویندوز با Python و PyQt5.

## ویژگی‌ها

- **کاملاً آفلاین** — بدون نیاز به اینترنت یا سرور
- **رابط فارسی RTL** — مناسب کاربران فارسی‌زبان
- **پایگاه داده SQLite** — ذخیره محلی روی سیستم
- **تقویم شمسی (جلالی)** — برای تمام تاریخ‌ها
- **ماژول‌های اصلی:**
  - مدیریت سرفصل حساب‌ها (کدینگ ۵ سطحی)
  - ثبت اسناد حسابداری با پیگیری سررسید
  - صندوق (ورود/خروج وجه نقد)
  - دفتر معین، دفتر کل، تراز آزمایشی، صورت سود و زیان
- **خروجی Excel و PDF** از گزارش‌ها
- **پشتیبان‌گیری و بازیابی** دیتابیس
- **نمایش مبلغ به حروف** — زیر هر فیلد مبلغ (بدهکار، بستانکار، صندوق)، معادل ریالی مبلغ به‌صورت زنده به حروف فارسی نوشته می‌شود
- **هشدار سررسید** — هنگام باز شدن برنامه، اسناد سررسیدگذشته و نزدیک‌به‌سررسید (تا ۷ روز آینده) نمایش داده می‌شوند
- **چاپ رسید تک‌سندی** — از تب «اسناد حسابداری» یا «صندوق»، برای هر سند/تراکنش می‌توان یک فیش PDF (شماره، تاریخ، شرح، مبلغ به عدد و حروف، جای امضا) ساخت
- **داشبورد** — تب اول برنامه؛ خلاصه درآمد، هزینه، سود/زیان ماه جاری، موجودی صندوق، و نمودار میله‌ای روند ۶ ماه اخیر

## معماری دیتابیس

### جدول `accounts` (سرفصل حساب‌ها)
| ستون | نوع | توضیح |
|------|-----|-------|
| id | INTEGER | شناسه |
| code | TEXT | کد حساب |
| name | TEXT | نام حساب |
| parent_id | INTEGER | حساب والد |
| level | INTEGER | سطح (۱=گروه، ۲=کل، ۳=معین، ۴=تفصیلی، ۵=تفصیلی شناور) |
| account_type | TEXT | نوع (asset, liability, equity, income, expense) |

### جدول `journal_entries` (اسناد)
| ستون | نوع | توضیح |
|------|-----|-------|
| id | INTEGER | شناسه |
| entry_number | INTEGER | شماره سند |
| entry_date | TEXT | تاریخ (شمسی) |
| due_date | TEXT | سررسید |
| description | TEXT | شرح |

### جدول `journal_lines` (سطرهای سند)
| ستون | نوع | توضیح |
|------|-----|-------|
| id | INTEGER | شناسه |
| journal_entry_id | INTEGER | شناسه سند |
| account_id | INTEGER | حساب |
| debit | REAL | بدهکار |
| credit | REAL | بستانکار |
| line_description | TEXT | شرح سطر |

## راهنمای نصب و اجرا

### مرحله ۱: نصب Python

1. به [python.org](https://www.python.org/downloads/) بروید
2. **Python 3.10 یا بالاتر** را دانلود و نصب کنید
3. هنگام نصب، گزینه **"Add Python to PATH"** را فعال کنید
4. نصب را با دستور زیر بررسی کنید:

```bash
python --version
```

### مرحله ۲: دانلود پروژه

پوشه `accounting_app` را در محل دلخواه کپی کنید، سپس در ترمinal (CMD یا PowerShell) وارد پوشه شوید:

```bash
cd accounting_app
```

### مرحله ۳: نصب کتابخانه‌ها

```bash
pip install -r requirements.txt
```

### مرحله ۴: اجرای برنامه

```bash
python main.py
```

دیتابیس به‌صورت خودکار در مسیر زیر ساخته می‌شود:

```
C:\Users\<نام کاربر>\Documents\HesabdariApp\accounting.db
```

## راهنمای ساخت فایل EXE (PyInstaller)

برای اجرا روی ویندوز **بدون نصب Python**:

### پیش‌نیاز

```bash
pip install pyinstaller
```

### ساخت exe

در پوشه پروژه:

```bash
pyinstaller build.spec
```

یا بدون فایل spec:

```bash
pyinstaller --onefile --windowed --name Hesabdari main.py
```

فایل اجرایی در پوشه `dist/` ساخته می‌شود:

```
dist/Hesabdari.exe
```

### نکات PyInstaller

- فایل `Hesabdari.exe` را می‌توانید روی هر ویندوزی کپی و اجرا کنید
- اولین اجرا ممکن است چند ثانیه طول بکشد
- آنتی‌ویروس‌ها گاهی فایل‌های PyInstaller را هشدار می‌دهند — این طبیعی است
- برای ساخت نصب‌کننده (installer) می‌توانید از [Inno Setup](https://jrsoftware.org/isinfo.php) استفاده کنید

## راهنمای استفاده

### ۱. سرفصل حساب‌ها
- از تب «سرفصل حساب‌ها» حساب‌های جدید بسازید
- ساختار: گروه → کل → معین → تفصیلی
- حساب‌های پیش‌فرض هنگام اولین اجرا ایجاد می‌شوند

### ۲. ثبت سند
- تب «اسناد حسابداری» → «سند جدید»
- حداقل ۲ سطر با جمع بدهکار = بستانکار
- فیلد «سررسید» برای پیگیری اسناد اقساطی

### ۳. صندوق
- «ورود وجه» یا «خروج وجه» برای ثبت سریع
- موجودی لحظه‌ای در بالای صفحه نمایش داده می‌شود

### ۴. گزارش‌ها
- بازه تاریخی را انتخاب کنید → «نمایش گزارش»
- خروجی Excel یا PDF بگیرید

### ۵. پشتیبان‌گیری
- منوی «فایل» → «پشتیبان‌گیری»
- فایل `.db` را در جای امن نگه دارید
